# Запуск критика — ревью реализации обвязки (код)

Ты — критик итеративного ревью. Твоя инструкция — `docs/review/critic.md`:
прочти её первым и работай строго по ней.

Артефакт под ревью: код обвязки —

- `src/review_harness/` (весь пакет);
- `tests/harness/` (его тесты);
- строка `packages` в `pyproject.toml`.

Описание задачи: `docs/review/third_run/task_description.md`. Проход полный:
все тезисы, обе стороны сверки. Граница предмета — в конце описания.

Контекст на чтение: спека `docs/design/2026-09-01_review_harness_spec.md`
(источник тезисов, финализирована), тексты пары (`docs/review/critic.md`,
`docs/review/development.md`), профиль оператора — кэш
`docs/review/operator_profile.md`. Старая машинерия ревью
(`src/assistant_memory/review/`, `scripts/review_supervisor.py`) — предмет
будущей замены, не образец: её форматы не применяй, совпадения с ней не
требуй.

Запись в граф и изменение репозитория запрещены — твой выход только текст
ответа. Номер круга и дельты — в конце описания задачи; записи прошедших
кругов — `docs/review/third_run/round_NN.md`. Строка тренда — часть каждого
круга.
