# Круг 10 (третий прогон: код обвязки) — проход критика (sol) и исходы

Дата: 2026-09-01. Версия артефакта: после правок круга 9 (98 тестов).
Тренд: 2 находки новой территории / 7 потомков прежних правок.
Privacy-находка прошлых кругов СНЯТА критиком по решению оператора
(«гигиена, не оборона»). Вердикт: не готова; решает оператор.

## Исходы (разработка; все — рабочий слой; 98 тестов, pytest exit 0)

1. Отказ открытия стрима ложно рапортует «убит» — **согласен**: результат
   tree.kill() учитывается, отказ различает подтверждённую и
   неподтверждённую смерть.
2. Контракт файловых ошибок частичен — **согласен**: мета и файлы ворот —
   через единый контрактный читатель (диск + кодировка); записи лаунчера,
   буфера, профиля машины, заготовки CLI обёрнуты; mkdir тоже.
3. Исполнимость мимо профильного окружения — **согласен**: shutil.which
   ищет в PATH из наложенного профильного env; значения env строго
   строковые (типизация).
4. Полнота пачки по количеству — **согласен**: полнота меряется
   идентичностью вопросов; структура элементов проверяется при
   восстановлении.
5. Хвост пивота privacy — **согласен** (перенос решённого оператором):
   спека §3 переписана под «гигиена, не оборона; публикация закрыта R1.1»;
   докстринги и тексты отказов кода приведены к той же семантике.
6. Эскейпы неоднозначны — **согласен**: при не-UTF-8 выводе точные байты
   ложатся raw-файлом рядом со стримом; текст остаётся с эскейпами; тезис
   переформулирован честно.
7. Журнал уточнений с исходным вопросом — **согласен**: журналируется
   фактический текст, на который отвечал оператор.
8. Долговечность буфера без dir-fsync — **согласен**: fsync каталога на
   append, перезаписи и удалении (POSIX).
9. Типы пары до .strip() — **согласен**: типизированная проверка всех
   полей пары с отказом по контракту.

## Проход критика дословно

Полный проход круга 10 выполнен. 98 тестов проходят. Предыдущую
privacy-находку по существу снимаю: оператор явно переопределил правило
как гигиену Git, а не защитную границу. Однако после правок остаются
следующие дефекты.

1. [HIGH, подтверждено] Отказ открытия stream-файла всё ещё может ложно
сообщить, что дерево убито: результат tree.kill() игнорируется, причина
безусловно утверждает «процесс убит деревом»; тест проверяет только
исключение. Сценарий: Job Object или killpg отказал; роль продолжает
менять файлы, а оператору сказано, что она остановлена. Класс: MVP-блокер
живучести; потомок.

2. [HIGH, подтверждено] Контракт «любая файловая ошибка и битая кодировка —
HarnessError» частичен: мета круга и gate-файлы читаются напрямую без
UnicodeDecodeError; записи в launcher, PairBuffer, machine-profile и CLI
выпускают сырые OSError. Класс: MVP; потомок.

3. [HIGH, подтверждено] Проверка исполнимости не использует окружение, с
которым реально запускается роль: check_executables() ищет по PATH
обвязки, а Popen получает PATH после наложения profile.env. Дополнительно
проверяется только внешний тип env=dict, не строковые типы значений.
Класс: MVP-блокер запускового знания; потомок env-правки.

4. [HIGH, подтверждено] Восстановление ворот определяет полноту пачки по
количеству, а не по идентичности вопросов: две копии ответа на «Первый?»
закрывают пачку с неотвеченным «Вторым?». Элементы не проверяются на
question/answer. Класс: MVP, ложное закрытие развилки; потомок.

5. [HIGH, подтверждено] Пивот privacy оставил противоречащие источники
семантики: описание ссылается на финализированную спеку, спека требует
«вне Git ради предотвращения публикации», новое решение оператора —
«гигиена». Следующий разработчик исполнит спеку и вынесет каталоги
вопреки последнему слову; следующий критик получит два несовместимых
критерия. Класс: хвост легитимного пивота, блокер однозначности; новая
территория.

6. [MEDIUM, подтверждено] Эскейпы не сохраняют однозначное свидетельство:
байт 0xFF и четыре символа «\\xff» неразличимы; тезис обещает точную
байтовую запись. Класс: доказательность; потомок.

7. [MEDIUM, подтверждено] История многократного уточнения записывается
неверно: журнал получает исходный question, хотя оператор отвечал на текст
уточнения; дословные формулировки уточнений не сохраняются — пара обмена
невосстановима. Класс: аудит слова оператора; потомок.

8. [HIGH, правдоподобно] Долговечность охватила только RunCatalog: буфер
досылки не делает directory-fsync на append/rewrite/unlink — пара может
исчезнуть после отключения питания или вернуться и уйти в граф повторно.
Класс: порча сырья профиля; потомок fsync-правки.

9. [MEDIUM, подтверждено] Повреждённая пара даёт сырой traceback:
validate() зовёт .strip() без проверки типов; поле-число валит pending()
AttributeError, хвост буфера недоступен. Класс: MVP-восстановление; новая
территория.

Тренд: 2 находки на новой территории / 7 потомков прежних правок.
Вердикт: не готова; финализацию решает только оператор.
