# Круг 2 (второй прогон: спека обвязки) — проход критика (sol) и исходы

Дата: 2026-09-01. Версия артефакта: после правок круга 1.
Тренд: 0 находок новой территории / 3 потомка прежних правок.
Вердикт критика: к финализации не готова; решает оператор.
Прошлые находки: разрывы ведения цикла, немедленной записи, промежуточной
доставки, перечня носителей и распознавания смерти — закрыты.

## Исходы (разработка, согласовано с оператором)

1. Буфер сырья вне новой защиты приватности — **вопрос критика к оператору,
   решён**: буфер — тот же класс данных, вне git и публикуемой истории
   («да, их тоже в игнор»). Попутно оператор зафиксировал общий **критерий
   читателя** для состава git (в git — адресованное стороннему читателю:
   спеки, код с тестами, семантические карты, пользовательская документация,
   тексты процессов-продуктов; материал личного процесса разработки — вне
   git, долговечность на диске и в графе; спорное решает оператор).
   Записан в .gitignore и REPO_REQUIREMENTS.
2. «Висящее не блокирует» двусмысленно — **согласен, рабочий слой**:
   уточнено — не блокируется только безусловная финализация словом
   оператора; движение цикла по вопросу, ждущему его семантического решения,
   останавливается до ответа.
3. Два источника порогов без правила соотношения — **развилка оператора,
   решена его чтением**: параметры последовательны, а не конкурирующи —
   окно распознавания смерти (профиль машины, заземлено фактами среды) +
   время уведомления после распознавания (профиль оператора); полное время
   до знания — сумма, свойство среды; действующее окно называется на старте
   прогона. Акт: «Да, записываем».

## Проход критика дословно

Полный проход выполнен по всем тезисам и в обе стороны. Большинство находок
первого круга устранено материально; осталось три потомка правок.

1. Буфер сырья профиля остался вне новой защиты от публикации приватных
данных. Каталог прогона выведен из Git именно потому, что дословный текст
может содержать приватные сведения. Буфер досылки также хранит полные обмены
с оператором, но спецификация не требует исключать его из публикуемой
истории. Сценарий: граф недоступен, полный обмен записывается в буфер внутри
репозитория. Реализация считается соответствующей спецификации, даже если
буфер попадает в Git и публичную репу. Приватность каталога защищена, но
тот же класс данных утекает через новый носитель. Серьёзность: высокая при
срабатывании. Достоверность: правдоподобно. Происхождение: потомок правок
по буферу сырья и приватности. Вопрос оператору: уверены ли вы, что решение
было понято как относящееся только к каталогам прогонов, но не к буферу
полных обменов?

2. Висящее промежуточное решение одновременно блокирует и не блокирует цикл.
Правило промежуточных ворот говорит, что цикл ждёт ответа и не подменяет его
решением разработки. Следующее правило без уточнения говорит, что висящее
«не блокирует». По контексту второе, вероятно, означает «не блокирует
безусловную финализацию оператором», но буквальное прочтение шире.
Сценарий: на фиксации семантическая правка; одна реализация останавливает
движение до ответа, другая продолжает цикл — и разработка фактически
применяет или обходит семантическое решение без оператора. Серьёзность:
высокая при неверном прочтении, блокер однозначной семантики ворот.
Достоверность: правдоподобно. Происхождение: потомок правки по промежуточным
воротам.

3. У порогов наблюдения два источника без правила смыслового соотношения.
Пороги объявлены параметрами одновременно профиля машины и профиля
оператора; не сказано, разные ли это пороги, общее ограничение или
приоритет. Сценарий: профиль машины допускает пять минут сетевого молчания,
профиль оператора требует сообщить о смерти через минуту; одна реализация
убивает живую сессию, другая нарушает обещанное конечное время обнаружения.
Серьёзность: средняя. Достоверность: подтверждено как неоднозначность.
Класс риска: несколько машин или смена оператора. Происхождение: потомок
правки по владельцу порогов.

Тренд: 0 находок на новой территории / 3 потомка прежних правок.
Мнение критика: ещё не готова к финализации — первая находка затрагивает
действующую модель угроз, вторая допускает обход владения семантикой
оператором. Финализацию решает только оператор.
